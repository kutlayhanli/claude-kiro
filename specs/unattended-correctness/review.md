| R1 | Every rerun's cost per merged task must not exceed the first equity E2E's, which ran on OpenCode with Muse Spark. | R7 | The missing-command rules miss two cases: the provider is Done but the command is still missing, and the task is its own provider. Without a rule the workflow can loop on wait-and-retry or misroute a test conflict or implementation bug. | The spec already covers both. 12.5 applies only when "another unfinished task" provides the command, so a Done provider or the task itself gets no edge (`liveEdgeDecision` returns `none`, and P-24 adds an edge only when P is unfinished). | R8 | "Not running" is never defined observably.
